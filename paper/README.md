Compile with `latexmk -pdf main.tex` (or pdflatex + bibtex + pdflatex x2).
`numbers.tex` and `tables/*.tex` are generated by `../src/make_paper_tables.py`; do not edit them by hand.
`spconf.sty` and `IEEEbib.bst` are the official IEEE Signal Processing Society conference style files.
Figures are read from `../results/analysis/figures/`.
